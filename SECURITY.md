# Security Policy

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities involving BLE command
authorization, exported Android components, signing material, local media data,
or sensitive information in logs.

Use GitHub's private vulnerability reporting for this repository. Include:

- the affected commit or version;
- the Sony/Android and iPhone/iOS versions;
- reproducible steps and expected impact;
- whether physical proximity, an existing BLE connection or local device access
  is required;
- a minimal redacted log or proof of concept when safe.

You should receive an acknowledgement through the GitHub security advisory. No
fixed response-time guarantee is currently offered because this is a
maintainer-run community project.

## Supported versions

Security fixes target the latest code on the default branch and the latest
published pre-release. Older snapshots are not maintained separately.
